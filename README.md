# Hello World App

A simple Flask web application that displays "Hello World" and shows a random name from a SQLite database.

## Setup

1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```

2. Run the application:
   ```
   python app.py
   ```

3. Open your browser and go to: `http://127.0.0.1:5000`

## Features

- Displays "Hello World" message
- Shows a random name from the database
- Click the button to refresh and get another random name
- Database is automatically created with sample names on first run
